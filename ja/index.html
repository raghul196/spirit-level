水平器とは？

水平器（バブルレベル）は、面が完全に水平または垂直であるかを確認するための道具です。建設、大工仕事、住宅のDIYに欠かせない道具です。

従来の水平器には気泡入りの小さなガラス管があります。気泡が2本の線の間の中央にあれば面は水平です。このオンライン水平器はスマートフォンのセンサーを使って同じことをデジタルの精度で行います。

このオンラインバブルレベルの使い方

このオンラインバブルレベルはスマートフォンを精密な水平器に変えます。デバイスの内蔵センサーを使って面の水平を確認します。アプリのインストール不要で、ブラウザ上で動作します。

主な機能

  • 即時測定：スマートフォンを面に置いた瞬間からリアルタイムで角度を表示します。
  • 2つのモード：平面には「水平モード」、垂直面には「垂直モード」を使用します。
  • シンプルな操作：仮想気泡が実物の水平器と同様に視覚的なガイドを提供します。
  • ゼロボタン：任意の面でキャリブレーションしたり、カメラの出っ張りを補正できます。
  • 音声アラート：面が完全に水平になるとビープ音でお知らせします。

精度について

このオンライン水平器はほとんどのDIY作業に適していますが、プロ用のキャリブレーション済み水平器の代替にはなりません。精度はスマートフォンのセンサーに依存し、小さな振動が測定値に影響する場合があります。最良の結果を得るには、以下に説明するキャリブレーション方法をお試しください。

各部の説明

このオンライン水平器には「水平」と「垂直」の2つのモードがあります。各モードの構成要素をご説明します。

水平モード

  • 円形ダイヤル：全方向の面の傾きを示す円形の水準器です。
  • メイン気泡：円形ダイヤル内の気泡です。中央にあれば面は水平です。
  • 縦横レベル：前後方向（ピッチ）と左右方向（ロール）の傾きを示す2つの矩形レベルです。
  • 角度表示：面の正確な角度を度数で表示します。

垂直モードの各部

  • 垂直レベルボックス：垂直面を確認するためのクラシックな水平器インターフェースです。
  • 垂直気泡：垂直レベル内の気泡です。2本の線の間の中央に合わせると完全な垂直角度が得られます。
  • 垂直角度：正確な垂直角度を度数で表示します。

オンライン水平器で面を水平にする方法

  1. 「水平」モードを選択：モードスライダーで「水平」ボタンがアクティブになっていることを確認します。
  2. デバイスを置く：測定したい面にスマートフォンまたはタブレットを平らに置きます。
  3. 数値を確認：気泡と角度表示がリアルタイムで傾きを示します。
  4. 面を調整：メイン気泡が円形ダイヤルの中央に来て、両方の角度が0.0°になるまで面を動かして調整します。

壁のフレームを水平にする方法

  1. 「垂直」モードを選択：モードスライダーで「垂直」ボタンがアクティブになっていることを確認します。
  2. デバイスを当てて開始をタップ：スマートフォンまたはタブレットを測定したい垂直面に対して直立させ、開始を押します。
  3. 数値を確認して調整：垂直気泡と角度表示がリアルタイムで垂直方向の傾きを示します。気泡が中央に来て角度が0.0°になるまで調整します。

測定精度を向上させる方法

シンプルな2ステップのキャリブレーション方法を使うことで、測定精度を大幅に向上させ、センサーのバイアスを補正できます。 この方法はスマートフォン固有のゼロオフセット誤差のほとんどを打ち消します。

  1. 最初の測定：測定したい面にスマートフォンを置き、角度の値を記録します（例：0.8°）。
  2. 2回目の測定：持ち上げずに同じ場所でスマートフォンを正確に180°回転させ、2回目の値を記録します（例：-1.0°）。
  3. 真の傾きを計算：真の角度は2つの測定値の平均です。例：(0.8 + (-1.0)) / 2 = -0.1°。これは面がほぼ水平であることを示します。

180°回転法でセンサー誤差を打ち消し、より正確な測定を実現します。

カメラの出っ張りへの対処

最新のスマートフォンにはカメラの出っ張りがあり、完全に平らに置けないことがあります。これは正確な測定の妨げになりますが、ゼロボタンで簡単に補正できます。

  1. 置いて確認：スマートフォンを面に置きます。カメラの出っ張りにより、安定した微妙な傾きが生じ、ゼロ以外の値が表示されます。
  2. ゼロを押す：ゼロボタンをタップします。これにより現在の傾いた位置を新しい「0°」の基準点として設定します。
  3. 正確に測定：表示が0°になります。カメラの出っ張りの影響がキャンセルされ、面に対して正確な測定が可能になります。

「ゼロ」を使ってカメラの出っ張りによる傾きを補正します。

水平器を使える場面

オンライン水平器はさまざまな作業に役立ちます：

  • 写真・アートの掛け方：写真や絵がまっすぐに飾られているか確認できます。
  • 家具の組み立て：テーブル、椅子、その他の家具が安定して水平であることを確認できます。
  • 家電の設置：洗濯機の振動を防いだり、冷蔵庫が効率よく動作するよう水平を確認できます。
  • 建設・大工仕事：壁が垂直に、床が水平になっているかを確認できます。
  • 写真撮影：三脚のカメラを水平にして、傾いた写真を防げます。
